The New Computer Modern font in this folder (chtml/woff2/)
==========================================================

MathJax 4.1.3's default font, mathjax-newcm, is MathJax's conversion of
Antonis Tsolomitis's New Computer Modern fonts (npm package
@mathjax/mathjax-newcm-font@4.1.3). Each woff2 file names the GUST Font
License in its own name table; the notices below are the ones the files
carry. The npm package does not include the licence text, so the
simulator's scripts/vendor-mathjax.mjs copies it here, from
licenses/MathJax-NewCM-GUST-FONT-LICENSE.txt in the simulator's repository,
together with the LaTeX Project Public License 1.3c that it refers to
(LPPL-1.3c.txt, beside this file).

The package's scripts (chtml/dynamic/) are MathJax's own code, under the
Apache License 2.0 its package.json declares; that text is in LICENSE,
beside this file.
